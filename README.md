# مستندات پایگاه داده سرویس ایمیل

## معرفی کلی

این طرح پایگاه داده برای یک سرویس ایمیل طراحی شده است و امکان مدیریت کاربران، ارسال/دریافت ایمیل و ردیابی وضعیت خوانده شدن پیام‌ها را فراهم می‌کند.

## جداول پایگاه داده

### ۱. جدول `users`
اطلاعات حساب کاربری را ذخیره می‌کند.

**ستون‌ها:**
- `id`: شناسه منحصر به فرد (خود افزایشی)
- `name`: نام کامل کاربر (اجباری)
- `email`: آدرس ایمیل کاربر (اجباری، منحصر به فرد)
- `password_hash`: رمز عبور هش شده (اجباری)
- `created_at`: زمان ایجاد حساب کاربری
- `updated_at`: زمان آخرین به‌روزرسانی حساب کاربری

### ۲. جدول `mails`
پیام‌های ایمیل را ذخیره می‌کند.

**ستون‌ها:**
- `id`: شناسه منحصر به فرد (خود افزایشی)
- `code`: کد منحصر به فرد (قالب UUID)
- `sender_id`: شناسه کاربر فرستنده (ارجاع به `users.id`)
- `subject`: موضوع ایمیل (اجباری)
- `body`: محتوای ایمیل (اجباری)
- `sent_date`: زمان ارسال ایمیل
- `is_deleted`: پرچم حذف نرم
- `deleted_at`: زمان حذف ایمیل
- `deleted_by_id`: کاربری که ایمیل را حذف کرده (ارجاع به `users.id`)

**روابط:**
- حذف آبشاری اگر فرستنده حذف شود
- مقدار NULL اگر کاربری که ایمیل را حذف کرده، حذف شود

### ۳. جدول `mail_recipients`
گیرندگان هر ایمیل و وضعیت خوانده شدن را ردیابی می‌کند.

**ستون‌ها:**
- `mail_id`: ارجاع به ایمیل (ارجاع به `mails.id`)
- `recipient_id`: ارجاع به کاربر گیرنده (ارجاع به `users.id`)
- `is_read`: وضعیت خوانده شدن ایمیل توسط گیرنده

**روابط:**
- کلید اصلی ترکیبی (mail_id + recipient_id)
- حذف آبشاری اگر ایمیل یا گیرنده حذف شوند

## ایندکس‌ها

- `idx_mail_recipients_read`: بهینه‌سازی کوئری‌های بررسی وضعیت خوانده شدن برای ترکیب‌های خاص ایمیل/گیرنده

## ویژگی‌های طراحی

۱. **حذف نرم**: ایمیل‌ها می‌توانند به صورت منطقی حذف شوند بدون حذف فیزیکی
۲. **ردیابی تغییرات**: ثبت اینکه چه کاربری و چه زمانی ایمیل را حذف کرده
۳. **کارایی**: ایندکس وضعیت خوانده شدن، عملکرد کوئری‌های پرتکرار را بهبود می‌بخشد
۴. **یکپارچگی داده**: کلیدهای خارجی، یکپارچگی ارجاعی را حفظ می‌کنند
۵. **شناسه‌های منحصر به فرد**: کدهای شبه UUID برای ارجاع خارجی

این طرح از تمامی عملکردهای اصلی ایمیل پشتیبانی می‌کند و در عین حال یکپارچگی داده و کارایی سیستم را حفظ می‌نماید.
